## 2. Body font fix (applied in the final build)

`beamerposter` with `scale=1.0` redefines `\normalsize` to **24.88 pt**
(`beamerposter.sty`, `fontSizeX=24.88`). Block bodies use `\normalsize`, and
beamer's `normal text` font key is documented as "ignored currently", so the
`\setbeamerfont{normal text}{size=\fontsize{20}{25}}` line did **not** set body
text in builds 1–2 (measured 24.79 pt). The final build adds, immediately after
`\usepackage{beamerposter}`:

```latex
\renewcommand{\normalsize}{\fontsize{20}{25}\selectfont}
```

Measured body spans are now **19.93 pt** (20 pt TeX size rounded to PDF
points). This removed ~10 cm from the left column and ~8 cm from the right,
but it also made the left column much shorter than the right (see §0).

Note: all text is actually typeset in **Lato** (body) and **Raleway** (block
titles, headline, footline), because `beamerthemegemini.sty` calls
`\setsansfont{Lato}` and sets those families explicitly. `\setmainfont{TeX
Gyre Heros}` is present but does not reach sans text; per the author's
instruction the template fonts were **kept** (Heros was not forced). All fonts
are embedded.
